# SAM

Открыть `index.html` в браузере (или `python3 -m http.server`).

- `index.html` — разметка, `style.css` — стили, `app.js` — логика, `auth.js` — регистрация и вход (локальные аккаунты, пароль хранится как PBKDF2-хеш).
- Запускать через `python3 -m http.server` и открывать http://localhost:8000 (на file:// браузер может блокировать шифрование).
- Данные хранятся в localStorage браузера; резервная копия — Настройки → «Скачать копию».
- Синхронизация с Google Sheets и облачная база работают только внутри claude.ai (артефакт).

## Вход через Google и личная таблица

Вставьте Client ID в `app-config.js` (`googleClientId`). После этого экран входа показывает «Войти через Google», а данные каждого пользователя хранятся в его собственной таблице «Altyn Sauda» на его Google Диске (права только drive.file). Пока Client ID пустой, работает локальный вход по паролю.
